## Architecture note: mobile vs admin KYC routing

- **Mobile** → `EXPO_PUBLIC_API_BASE_URL` (monolith `:8080`) → `KycProxyController` → kyc-service
- **Admin console** → `VITE_KYC_API_BASE_URL` (kyc-service `:8082`) directly

Both are valid for v0.2.

## HTTP status convention

- **400** — request validation (`@Valid`, malformed JSON, missing headers)
- **422** — semantic rule violations thrown as `StashApiException` (e.g. admin reject without reason)

See `docs/v0.2-schema-reconciliation.md` for full detail.
